# Future Leaders College — IdentityX School Showcase

A premium, mobile-first digital school showcase concept built as a static website.

## What this demonstrates

This is designed to show a prospective school what a modern, shareable digital experience can look like — not just a conventional school website.

It includes:
- Cinematic hero and custom FLC crest treatment
- JSS1–SS3 positioning
- Campus visual walkthrough
- "A Day at FLC" story
- Principal message
- Student, parent and alumni testimonials
- School achievements
- Admissions conversion section
- WhatsApp and email enquiry actions
- Native social sharing / copy-link fallback
- Responsive mobile layout
- Scroll reveal animation
- No backend required

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Set the source to the `main` branch and `/ (root)`.
5. Save. GitHub will provide the public URL.

## Turn this into a real school

Replace:
- School name and crest
- Photography
- Principal name/message
- Testimonials
- Achievements
- Statistics
- Admissions copy
- WhatsApp number
- Email
- Existing school website/admission portal/social links

The site intentionally uses fictional Future Leaders College content and demo statistics. Do not present the demo claims as factual for a real institution.

## Photography

Demo photography is loaded from Unsplash URLs. For a client deployment, replace the images with the school's own high-quality campus/student photography.

## Product concept

This is the IdentityX School Showcase concept: a shareable digital experience schools can distribute through students, parents, alumni and social channels to help prospective families discover the school.
