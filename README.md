# IdentityX School Showcase

A premium, mobile-first school marketing showcase created as a demonstration of what IdentityX can build for schools.

## Demo school

**Aurelia Academy**  
A fictional premium Nigerian school created for demonstration purposes.

## What this demo demonstrates

- Cinematic school hero section
- Visual campus walkthrough
- Student-life timeline
- Principal message
- Parent, student and alumni testimonials
- School achievements
- Key school statistics
- Admissions conversion section
- WhatsApp enquiry CTA
- Email admissions CTA
- Native social sharing / copy-link fallback
- Responsive mobile layout
- Scroll reveal animations
- Open Graph metadata for social sharing
- No backend or build step required

## Run locally

Simply open `index.html` in a browser.

For the best experience, use a small local server such as VS Code Live Server.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.
7. GitHub will generate the public site URL.

## Suggested sales positioning

Don't sell this as "a website."

Sell it as:

> **A digital school showcase your students, parents and alumni can share.**

The goal is to help a prospective parent experience the school before they visit, then move naturally toward WhatsApp, enquiry or admission.
